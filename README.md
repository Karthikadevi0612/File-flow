✦ FileFlow – File Management Dashboard

A modern and responsive file management dashboard built using **HTML, CSS, and JavaScript**. FileFlow provides a simple interface to upload, organize, search, filter, and manage files efficiently.

🚀 Features

- Dashboard: Overview of file statistics.
- File Upload: Upload multiple files from your device.
- Search Files: Quickly find files by name.
- File Filtering: Filter files by PDF, images, and documents.
- File Sorting: Sort files by newest, oldest, and name.
- Storage Overview: Display storage usage.
- File Management: Select and delete files.
- Folder Management: Create new folders.
- Grid and List Views: Switch between different file layouts.
- Responsive Design: Adaptable layout for different screen sizes.

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive functionality
